# AI Roundtable

Codex 向けの AI 円卓会議スキルです。

進行役が論点を整理し、10 のペルソナが独立して見解を出し、相互に論点をぶつけたうえで、実行可能な結論とアクションプランにまとめます。

## Trigger

次のような依頼で使うことを想定しています。

- `AI円卓会議`
- `円卓会議`
- `10人の専門家`
- `10ペルソナ`
- `10職種レビュー`
- `$roundtable`

## Personas

- 営業
- マーケティング
- コンサル
- PM
- エンジニア
- デザイナー
- データ分析
- オペレーション
- CS
- リスク管理

## Output

標準出力は次の流れです。

1. 前提整理
2. 10 ペルソナの独立見解
3. ペルソナ間の議論
4. 進行役の結論
5. 優先順位、実行計画、KPI、リスク、未確認事項
6. 実会議のたたき台
