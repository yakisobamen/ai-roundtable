# Repository Rules

## Language

- Respond in Japanese by default unless the user requests another language.

## Public Repository Privacy

- This repository is intended to be public.
- Do not include company information, personal information, customer information, internal project names, internal file paths, private URLs, credentials, tokens, account names, or any content that could identify a person or organization.
- Use generic examples such as `Example Corp`, `example customer`, `example project`, and `https://example.com`.
- Before committing, check that new files do not contain private or identifying information.

## Skill Scope

- Keep this repository focused on the AI roundtable Codex skill.
- Avoid adding unrelated documents or generated artifacts.
